# Non-Doing (논두잉 / 無爲)

한국식 다도방에서 천천히 걷고, 다탁·소파·창가에 앉아 머무는 웹 경험입니다. 창호 너머의 자연, 업로드 음원, 선택형 60초 생각 내려놓기를 제공합니다. 편지함은 Supabase 연결 후 익명 응원을 주고받도록 구현되어 있으며, 미연결 상태에서는 명시적인 체험 화면으로 열립니다.

## 개발과 빌드

Node.js 24와 Python 3을 사용합니다.

```sh
npm ci
npm run build
npm test
npm run dev
```

`npm run dev`는 저장소의 정적 파일을 8000 포트로 제공합니다. 스타일 수정 후 `npm run build`를 다시 실행합니다. Tailwind CSS 4는 빌드 때 로컬 CSS로 생성되므로 외부 CDN·폰트·이미지 요청은 없습니다. 음원은 사용자 제공 MP3를 같은 사이트의 `assets/audio/`에서 필요할 때 불러옵니다. 빌드 결과는 `dist/`에 생성됩니다.

## 화면과 조작

- 진입 즉시 목재 마루·한지 창호·다탁·소파·창가 자리가 있는 다도방이 나타납니다.
- 바닥 클릭/터치 또는 방에 포커스한 뒤 방향키/WASD로 이동합니다. 모바일은 방을 밀어서 둘러볼 수 있습니다.
- 각 자리의 생각하기 버튼을 누르면 가구를 피해서 걸어가고, 앉는 동작을 마친 뒤 생각 입력창이 열립니다. 다탁·소파·창가 단축 버튼으로도 이동할 수 있습니다.
- 상단 버튼으로 선택한 음원을 켜고 끕니다. 아래 메뉴에서 6개 음원 중 하나를 선택할 수 있으며, 선택한 음원은 끝나면 자동으로 다시 재생됩니다. 기본은 빗소리이며 자동 재생은 하지 않습니다. 음원을 바꿔도 소리를 끈 상태는 유지됩니다. 탭이 숨겨지면 풍경 애니메이션은 쉬고 소리는 유지합니다. 기기·브라우저의 백그라운드 재생 제한은 적용될 수 있습니다.
- EN / 한국어 버튼으로 언어를 전환합니다. `?lang=en`으로 영어 화면에 진입할 수 있습니다.
- ‘풍경만 보기’로 UI를 숨기고 ‘돌아오기’ 또는 Escape로 복원합니다.
- ‘생각 내려놓기’에서는 최대 140자의 생각을 별빛 또는 연못의 투명한 물방울에 담습니다. 60초 동안 호흡 안내와 함께 작아지고 소멸합니다. 연못 모드는 물속 빛·수초·바닥 조약돌과 천천히 헤엄치는 물고기를 그리며, 물방울은 마지막에 잔물결로 스며듭니다. 동작 줄이기 설정에서는 물고기와 수면의 움직임을 멈춥니다. 호흡 주기는 들이쉬기 4초, 편히 머물기 2초, 내쉬기 6초이며 마지막 6초에는 마무리 안내가 나옵니다.
- 입력은 서버·영구 저장소에 기록하지 않습니다. 완료 또는 중도 종료 시 입력창과 렌더링용 문자열을 비웁니다. 브라우저 메모리의 보안 삭제를 보장하는 기능은 아닙니다.
- 소리는 명시적으로 켰을 때만 재생됩니다. Web Audio 오실레이터로 싱잉볼·드론·별가루 벨을 합성합니다.
- 모바일 세로·가로 화면, 안전 영역, 키보드 포커스, 동작 줄이기 설정을 지원합니다.
- 공유 버튼은 지원 기기의 기본 공유창을 열거나 HTTPS 환경에서 주소를 복사합니다. 로컬 미리보기에서는 배포가 필요하다는 안내를 표시합니다.

## Vercel 배포

GitHub에 변경을 푸시한 뒤 Vercel에서 저장소 `Min8309/non_doing`를 Import합니다. Framework Preset은 Other, Root Directory는 저장소 루트입니다. `vercel.json`이 `npm ci`, `npm run build`, Output Directory `dist`를 지정합니다. 다도방·음원·60초 의식만 이용할 때는 환경 변수가 필요 없습니다. 익명 편지 기능은 Supabase와 서버 환경 변수, 검수 워커 설정이 필요합니다. Vercel은 `api/`의 Node 함수를 함께 배포합니다. 이후 연결된 프로덕션 브랜치에 푸시하면 Vercel이 자동 배포합니다.

## 확인된 범위

Chromium에서 320×568, 390×844, 844×390, 1440×1000 화면의 언어 전환, 풍경 모드, 로컬 공유 안내, 두 캡슐, 호흡 전환, 완료·중도 종료 시 입력 비우기를 확인했습니다. 60초 흐름은 브라우저 시계를 제어해 검사했습니다. 외부 서비스 요청 없음, 동작 줄이기, Web Audio 노드 생성·음소거·종료도 확인했습니다. 실제 휴대폰·Safari와 청각적 음질은 별도 확인이 필요합니다.

## 익명 응원 편지함

다도방의 작은 편지함 또는 하단 편지함 버튼으로 엽니다. [연결 안내](docs/supabase-setup.md)에 따라 SQL, Supabase 익명 인증, Vercel 환경 변수, 분 단위 검수·배달 워커를 설정해야 실제 교환이 활성화됩니다. 연결 전 예시를 실제 사용자의 편지나 성공적인 전달로 표시하지 않습니다.

- 고민 50–300자, 응원 50–400자(공백 제외), 하루 고민 1개와 티켓/신뢰도/쿨다운 제한을 서버에서도 확인합니다.
- 직접 테이블 접근은 RLS와 권한으로 차단하고 소유권을 확인하는 RPC만 공개합니다.
- 승인된 사연에만 응원할 수 있으며 자기 답장·중복 답장을 막고 1개 사연의 최대 답장 3개를 잠금 하에 예약합니다.
- 패턴 검사와 LLM 문맥 검수 후 승인·사람 검수·격리를 분리합니다. 검수 실패 시 자동 승인하지 않습니다.
- 승인된 응원은 5–20분 대기 후 워커가 전달합니다. 수신자는 감사 스티커 한 장만 보낼 수 있고 텍스트 재답장은 없습니다.
- 신고/숨기기는 작성자를 차단하고 해당 발신자의 기존 및 이후 편지를 가립니다. 신고 검토 기록은 제한적으로 남으므로 전체 원본 영구 삭제로 설명하지 않습니다.
- 익명 인증은 다른 사용자에게 신원을 드러내지 않는 방식이며 브라우저 지문을 수집하지 않습니다. 원래 제안의 기기 지문/IP 서브넷 추적은 구현하지 않았습니다. 새 익명 계정 남용에는 별도의 운영 레이트 리밋과 CAPTCHA 연동이 필요합니다.
- AI 검수나 키워드 필터는 모든 악성 메시지를 막는다는 보장이 아닙니다. 격리된 편지에는 실제 운영자의 검수가 필요합니다.

`npm test`는 로컬 PostgreSQL 엔진에서 DB 규칙을 실제 실행하고 서버 입력/인증 경계를 검증합니다. 실사용 Supabase·OpenAI·배포 후 두 세션 간 전달 검증은 외부 설정 후 별도로 수행해야 합니다.

## 범위

움직이는 인물은 이 브라우저의 로컬 아바타입니다. 실시간 다른 사용자 아바타, 채팅, 접속자 집계, 분석·추적 기능은 없습니다. 편지 작성은 별도 명시적 동작이며 60초 생각 입력은 자동으로 편지 서버에 전송하지 않습니다.

## 최근 검증

- 다도방: 320×568, 390×844, 844×390, 1440×1000에서 다탁·소파·창가로 실제 프레임 이동, 가구 회피, 앉기 완료 후 입력창 열기, 중도 이동·영어·연못 의식 연동 확인.
- 편지함: 320×568, 390×844, 1440×1000에서 미연결 체험과 모의 API 연결 화면, 길이 제한·글 제출·스티커·숨기기·닫을 때 초안 비우기 확인. 모의 API 검사는 실제 외부 Supabase 전달 검사가 아닙니다.
- 자동 테스트 5개: PostgreSQL 규칙과 검수 실패 격리, 입력 검사, 서버 인증·원본 검증·비밀정보 비노출 확인.
- `npm run build`, JavaScript 구문 검사, `git diff --check` 통과. 실제 Supabase 연결·OpenAI 호출·예약 작업·Vercel 배포 결과는 외부 설정 후 확인해야 합니다.
