# Non-Doing (논두잉 / 無爲)

마음을 흘려보내는 웹 경험을 위한 초기 프로토타입입니다.

## 현재 기준 코드

`index.html`은 제공된 기초 HTML/CSS/JavaScript 원문을 변경 없이 보존한 파일입니다. 현재 브라우저 제목과 화면 브랜드는 **마음 비우기 - Mind Drift / Mind Drift**이며, Non-Doing으로의 화면 제목 변경과 기능 개선은 아직 적용하지 않았습니다.

## 실행

`index.html`을 최신 브라우저로 열거나, 저장소 폴더에서 아래 명령으로 정적 서버를 실행합니다. 별도 패키지 설치나 빌드 과정은 없습니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 구현된 범위

- 최대 140자 생각 입력 및 글자 수 표시
- 별빛 / 조약돌 모드 선택과 Canvas 애니메이션
- 60초 타이머와 호흡 안내, 소멸 파티클, 재시작
- Web Audio API 기반 합성 배경음과 효과음

백엔드, 계정, 데이터베이스, 배포 설정은 포함하지 않습니다.

## 외부 의존성

- Tailwind CSS CDN: `https://cdn.tailwindcss.com`
- Google Fonts CSS 요청: `https://fonts.googleapis.com/css2?family=Pretendard:wght@300;400;500;600&display=swap`
- 브라우저 Canvas 2D 및 Web Audio API

외부 스타일과 폰트 요청에는 인터넷 연결이 필요하며, 해당 서비스의 가용성에 영향을 받습니다. 폰트를 불러오지 못하면 시스템 글꼴로 대체됩니다. 외부 CDN 리소스는 이 저장소에 포함되어 있지 않습니다.

## 원본의 알려진 한계

- 흘려보내기를 누르면 음소거 상태여도 소리가 켜집니다.
- 화면의 '완전히 소멸' 표현은 메모리 삭제를 보장하지 않습니다. 종료 시 입력창과 `thoughtObject.text`에 내용이 남고, 재시작은 입력창만 비웁니다.
- 자체 코드에는 입력을 서버로 전송하거나 브라우저 영구 저장소에 기록하는 처리가 없습니다. 다만 외부 스크립트와 폰트 요청이 있으므로 완전한 오프라인/네트워크 격리나 민감정보 보호를 보장하지 않습니다.

## 초기 점검

- JavaScript 구문 검사(`node --check`) 통과
- HTML 기본 중첩, 중복 ID 및 JavaScript DOM 참조 점검 통과
- 원본 검토 및 일반적인 비밀키/인증정보 패턴 검사에서 노출 항목을 발견하지 못함(완전한 보안 감사는 아님)
- 현재 실행 환경의 브라우저 프로세스 제한으로 실제 화면·오디오·60초 동작 및 외부 CDN 로딩은 검증하지 못함
